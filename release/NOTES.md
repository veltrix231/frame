## FRAME 1.0.1

Рамки выбора монитора и разрешения стали серыми. Кнопки раскрытия списков теперь тёмные и сочетаются с чёрным интерфейсом.

**Скачать:** выбери **FRAME-portable.zip** в разделе Assets, распакуй архив и запусти **ResolutionPicker.exe**.

---

Display and resolution selectors now have gray borders and dark dropdown buttons to match FRAME's black interface.

**Download:** select **FRAME-portable.zip** under Assets, extract it and run **ResolutionPicker.exe**. No installation is required.

**SHA256SUMS.txt** contains the archive's SHA-256 checksum.
