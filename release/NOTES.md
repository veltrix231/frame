## FRAME 1.0.0

**Скачать:** выбери **FRAME-portable.zip** в разделе Assets ниже, распакуй архив и запусти **ResolutionPicker.exe**. Установка не требуется.

Первая публичная версия FRAME:

- Выбор разрешения, частоты и монитора.
- Подтверждение режима с автовозвратом через 15 секунд.
- Поиск конфига Fortnite и выбор своего файла.
- Отдельная запись разрешения в Fortnite с включением «Только чтение» после записи.
- Список кастомных режимов NVIDIA, кнопки создания и обновления.
- Чёрный интерфейс, белый предпросмотр, FAQ, русский и английский языки.
- Ссылка на TikTok автора: [@lyorefreak](https://www.tiktok.com/@lyorefreak).

Перед записью конфига закрой Fortnite. Нижние четыре значения разрешения сохраняются как 1920 × 1080.

---

**Download:** select **FRAME-portable.zip** under Assets, extract it and run **ResolutionPicker.exe**. No installation is needed.

The first public FRAME release includes display and refresh rate selection, a 15-second rollback, Fortnite config detection and saving, NVIDIA custom mode navigation and refresh, a monitor preview, FAQ and English/Russian UI.

Close Fortnite before saving its config. The lower four resolution values are kept at 1920 × 1080. The config is set to Read-only after saving.

**SHA256SUMS.txt** contains the archive's SHA-256 checksum.
